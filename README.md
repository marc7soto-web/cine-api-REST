# cine-api-REST

API REST desarrollada con Express Framework y MongoDB Atlas para la administración de películas y actores.

## Tecnologías que se usaron

- Visual Studio
- Node.js
- Express
- MongoDB Atlas
- MongoDB Driver
- CORS
- GitHub
- Render

## Endpoints Película

POST /api/pelicula

GET /api/peliculas

GET /api/pelicula/:id

PUT /api/pelicula/:id

DELETE /api/pelicula/:id

## Endpoints Actor

POST /api/actor

GET /api/actores

GET /api/actor/:id

GET /api/actor/pelicula/:idPelicula
